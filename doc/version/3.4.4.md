## 更新内容

- 捷特文库改用在线文章与专栏，支持多标签筛选、摘要和专栏封面
- 优化 Markdown 阅读排版，新增目录导航、代码高亮与行号，以及 Mermaid 图表
- 完善文章图片缓存、按需尺寸处理和长按保存、复制链接、查看大图
- 重设计桌面端账号页，以三栏展示个人资料、组件收藏、任务和荣誉
- 优化移动端知识模块，统一顶部高度，新增主题标题，并调整算法设置入口
- 修复修改密码失败却提示成功的问题，展示具体失败原因并完善登录会话处理
- 优化 Android 安装包体积，目标版本升级至 Android 16（API 36）

## What's New

- Moved the article library and collections online, with tag filters, summaries, and collection covers
- Improved Markdown typography with table-of-contents navigation, syntax highlighting, line numbers, and Mermaid diagrams
- Added cached article images, responsive image sizing, and long-press actions to save images, copy links, and view full-size images
- Redesigned the desktop account page with profile, widget favorites, tasks, and honors in a three-column layout
- Refined mobile knowledge navigation with consistent header heights, themed headings, and improved algorithm settings placement
- Fixed false success messages when changing passwords and improved error reporting and session handling
- Reduced Android package size and updated the target SDK to Android 16 (API 36)
