常见问题

在线内容或插件信息加载失败怎么办？

请先确认网络连接正常，然后重新进入页面。部分内容来自第三方服务，短暂不可用时可稍后重试。若持续失败，请在反馈中附上系统版本、FlutterUnit 版本和问题截图。

组件示例和当前 Flutter 版本表现不一致怎么办？

Flutter 框架持续更新，部分属性、默认行为或视觉效果会随版本变化。请通过 GitHub Issue 告知组件名称、期望表现和当前截图，我们会核查并更新内容。

如何查找和收藏组件？

在组件首页使用搜索框输入 Widget 名称，并通过分类或筛选缩小范围。进入详情后可将组件加入收藏夹，收藏数据默认保存在本机。

保存插件卡片时提示相册权限怎么办？

请前往系统设置，为 FlutterUnit 开启“添加照片”权限。该权限只在您主动保存图片时使用；拒绝授权不会影响组件浏览等主要功能。

卸载后收藏数据能恢复吗？

收藏和偏好主要保存在应用本地。卸载或清除应用数据前，请自行备份重要内容；没有云同步时通常无法恢复。

提交问题时应该提供什么？

建议提供设备与系统版本、FlutterUnit 版本、复现步骤、期望结果、实际结果及截图。请勿在公开 Issue 中提交密码、令牌或其他敏感信息。

Frequently Asked Questions

Online content or package information does not load.

Check your connection and reopen the page. Some information comes from third-party services and may be temporarily unavailable. If the issue continues, include your OS version, FlutterUnit version, and a screenshot in your report.

A widget example differs from the current Flutter release.

Flutter evolves continuously, and properties, defaults, or visuals may change. Open a GitHub Issue with the widget name, expected behavior, and a current screenshot so we can review the example.

How do I find and favorite a widget?

Use the search field on the widget screen, then refine results by category or filter. Open a widget detail page to add it to a favorite folder. Favorites are stored locally by default.

Why does saving a package card require Photos access?

Enable Add Photos access for FlutterUnit in system settings. It is used only when you choose to save an image. Denying it does not affect core widget-browsing features.

Can I restore favorites after uninstalling?

Favorites and preferences are primarily stored locally. Back up anything important before uninstalling or clearing app data. Without cloud sync, recovery is generally not possible.

What should I include in a bug report?

Include your device and OS, FlutterUnit version, reproduction steps, expected and actual results, and screenshots. Never post passwords, tokens, or sensitive information in a public Issue.
