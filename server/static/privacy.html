本政策说明 FlutterUnit 如何处理信息。我们不出售您的个人信息，也不使用跨应用跟踪进行定向广告。

一、适用范围

本政策适用于 FlutterUnit 移动端、桌面端及其相关在线功能。您通过本应用访问的第三方网站或服务适用其自身隐私政策。

二、我们处理的信息

信息类型示例目的与存储
本地偏好与内容主题、语言、显示设置、收藏夹、组件浏览状态提供个性化体验，主要存储在您的设备中
应用与匿名标识应用版本、应用标识、应用首次运行时随机生成的 UUID接口兼容、内容服务识别和问题排查；UUID 不等同于 Apple 广告标识符
网络与请求信息IP 地址、请求时间、接口路径、语言设置提供新闻、文章、插件信息和在线内容；服务器可能在安全日志中临时记录
您主动选择的文件或图片导入的字体/资源文件、保存至相册的图片仅在您触发对应功能时处理
反馈信息邮件内容、Issue、设备与版本说明响应支持请求和定位问题

当前常规使用无需注册账号。项目中可能包含尚未启用或处于测试阶段的账号与同步代码；若未来正式提供账号、云同步或新增数据处理，我们将在启用前更新本政策并依法取得必要同意。

三、信息使用方式

  • 提供组件资料、示例代码、文章、新闻和插件信息；
  • 保存您的本地收藏和界面偏好；
  • 完成分享、文件选择、图片保存等由您主动发起的操作；
  • 保障接口安全、排查故障并改善应用质量；
  • 遵守适用法律法规和平台要求。

四、存储与安全

收藏夹、设置、缓存与内置数据库主要保存在本机应用沙盒中。卸载应用或清除应用数据可能导致这些内容丢失。在线请求采用服务所支持的安全措施；但互联网传输不存在绝对安全，我们会在合理范围内采取访问控制、最小化处理和必要的安全防护。

除法律另有要求外，安全日志仅在实现安全、排障和运营所需期间保留；用户主动发送的支持邮件或 Issue 将保留至问题处理完成或您请求删除。

六、第三方服务与外部链接

本应用可能通过公开网络服务获取 Flutter/Dart 插件信息、文章或新闻，并可能链接至 GitHub、pub.dev、作者网站及其他技术站点。第三方可能依据其政策处理 IP 地址、Cookie 或访问日志。我们建议您访问前查看其隐私政策。

应用使用的开源 SDK 可能提供文件选择、分享、偏好存储、数据库、网页展示和链接跳转等能力。我们仅在实现相应功能所需范围内调用这些能力。

七、信息共享与披露

我们不会出售您的个人信息。除您主动请求与第三方交互、完成服务所必需、获得您的授权，或法律法规及有权机关依法要求外，我们不会向第三方披露可识别您的信息。

八、您的选择与权利

  • 在应用内修改或重置偏好、缓存和收藏数据；
  • 在系统设置中管理照片等权限；
  • 通过卸载应用删除本地沙盒数据；
  • 联系我们查询、更正或删除您通过反馈渠道提交的信息；
  • 停止使用在线功能或本应用。

九、未成年人保护

本应用是开发学习工具，不以儿童为目标用户，也不会有意收集儿童个人信息。未成年人应在监护人指导下使用外部链接与在线内容。

十、政策更新

我们可能因功能、第三方服务或法律要求变化更新本政策。更新内容将在本页面公布，并标注新的生效日期；发生重大变化时，我们会通过合理方式提示。
