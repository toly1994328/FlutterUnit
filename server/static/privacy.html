本政策说明 FlutterUnit 如何处理信息。我们不出售您的个人信息，也不使用跨应用跟踪进行定向广告。

一、适用范围

本政策适用于 FlutterUnit 移动端、桌面端及其相关在线功能。您通过本应用访问的第三方网站或服务适用其自身隐私政策。

二、我们处理的信息

信息类型示例目的与存储
账户与认证信息邮箱、登录标识、加密后的密码凭据、验证码记录、第三方登录标识、账户状态注册、登录、绑定邮箱、验证身份和保障账户安全；存储于服务端
个人资料昵称、头像、签名及您主动填写的资料展示和管理您的账户；头像文件及资料存储于服务端

您主动选择的文件或图片导入的字体/资源文件、保存至相册的图片仅在您触发对应功能时处理
反馈信息邮件内容、Issue、设备与版本说明响应支持请求和定位问题

您可以不登录使用部分本地与公开内容功能；使用账户资料、跨设备身份或其他需要认证的在线能力时，需要注册或登录。

三、信息使用方式

  • 创建和认证账户、发送邮箱验证码、绑定邮箱及维护登录会话；
  • 展示昵称、头像和签名，并保存您主动提交的资料；
  • 提供组件资料、示例代码、文章、新闻和插件信息；
  • 保存您的本地收藏和界面偏好；
  • 完成分享、文件选择、图片保存等由您主动发起的操作；
  • 保障接口安全、排查故障并改善应用质量；
  • 遵守适用法律法规和平台要求。

四、存储与安全

账户信息、个人资料和您上传的头像在您使用账户服务期间存储于服务端；收藏夹、设置、缓存与内置数据库主要保存在本机应用沙盒中。卸载应用或清除应用数据可能导致本地内容丢失，但不会自动删除服务端账户。在线请求采用服务所支持的安全措施；但互联网传输不存在绝对安全，我们会在合理范围内采取访问控制、凭据保护、最小化处理和必要的安全防护。

除法律另有要求外，安全日志仅在实现安全、排障和运营所需期间保留；用户主动发送的支持邮件或 Issue 将保留至问题处理完成或您请求删除。

您可以在设备系统设置中撤回权限。撤回后仅对应功能可能不可用。

六、第三方服务与外部链接

当您主动选择 GitHub 或 Apple 登录时，相应平台会按照其政策处理授权信息，并向我们提供用于验证身份的标识、令牌以及您授权共享的资料。邮箱验证码会通过邮件服务完成投递。本应用还可能通过公开网络服务获取 Flutter/Dart 插件信息、文章或新闻，并可能链接至 GitHub、pub.dev、作者网站及其他技术站点。第三方可能依据其政策处理 IP 地址、Cookie 或访问日志。我们建议您使用前查看其隐私政策。

应用使用的开源 SDK 可能提供文件选择、分享、偏好存储、数据库、网页展示和链接跳转等能力。我们仅在实现相应功能所需范围内调用这些能力。

七、信息共享与披露

我们不会出售您的个人信息。除您主动请求与第三方交互、完成服务所必需、获得您的授权，或法律法规及有权机关依法要求外，我们不会向第三方披露可识别您的信息。

八、您的选择与权利

  • 在账户管理中查看或修改昵称、头像、签名、邮箱和密码；
  • 在应用内修改或重置偏好、缓存和收藏数据；
  • 在系统设置中管理照片等权限；
  • 通过卸载应用删除本地沙盒数据；
  • 在账户管理中发起注销，删除账户及依法无需继续保留的关联个人信息；注销通常不可恢复；
  • 联系我们查询、更正或删除您通过反馈渠道提交的信息；
  • 停止使用在线功能或本应用。

法律法规要求继续保存，或删除在技术上暂时难以实现的信息，我们将停止除存储和必要安全保护之外的处理，并在条件具备后删除或匿名化。

九、未成年人保护

本应用是开发学习工具，不以儿童为目标用户，也不会有意收集儿童个人信息。未成年人应在监护人指导下使用外部链接与在线内容。

十、政策更新

我们可能因功能、第三方服务或法律要求变化更新本政策。更新内容将在本页面公布，并标注新的生效日期；发生重大变化时，我们会通过合理方式提示。

3. How We Use Information

  • display and store profile names, avatars, signatures, and details you submit;
  • deliver widget references, examples, articles, news, and package information;
  • save local favorites and interface preferences;
  • complete sharing, file selection, and image-saving actions you initiate;

  • comply with applicable law and platform requirements.

4. Storage and Security

Account information, profile data, and avatars you upload are stored on our server while you use account services. Favorites, settings, caches, and built-in databases are primarily stored in the App sandbox on your device. Uninstalling the App may remove local data but does not automatically delete your server account. We apply reasonable transport security, credential protection, access controls, and data minimization, but no internet transmission can be guaranteed completely secure.

Unless law requires otherwise, security logs are retained only as needed for security, diagnostics, and operations. Support emails or Issues are retained until the matter is resolved or you request deletion.
